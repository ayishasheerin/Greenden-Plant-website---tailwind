🌿 Greenden

Greenden is a responsive online plant-selling website designed with a clean and modern interface for browsing plants and exploring plant products.

📌 Pages

The website includes three main pages:

* Home – Introduction to Greenden and featured plant content.
* Products – Browse the available plants and products.
* Contact – Contact information and an enquiry form.

✨ Features

* 🌿 Clean and modern plant-themed design
* 🪴 Product browsing page
* 📱 Fully responsive design
* 💻 Responsive across desktop, tablet, and mobile devices
* 📩 Contact page for user enquiries
* 🎨 Simple and user-friendly interface

🛠️ Technologies Used

* HTML5
* CSS3
* Tailwind CSS

📱 Responsive Design

Greenden is designed to provide a consistent experience across different screen sizes:

* Desktop
* Tablet
* Mobile
